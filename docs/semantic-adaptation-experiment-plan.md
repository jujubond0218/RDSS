# 面向目标域语义适配的描述选择实验

记录日期：2026-10-20。本文整理本次讨论中明确的研究问题、已有实验事实和下一步对照方法。它是实验设计记录，不代表后续实验已经完成，也不预设筛选一定优于全量融合。

## 研究问题与概念修正

本课题关注的“冗余”主要指**不适用于当前目标域或当前样本的语义证据**，不是同义改写或重复句子。例如，LLM 为“狗”生成“黑色的狗”这一合理描述，但目标数据集中的狗主要为黄色或白色；如果无差别聚合描述，黑色属性可能使类别文本原型偏离当前视觉分布。这里的类别和颜色仅为解释机制的假设例子，当前实际实验仍使用 DTD。

需要区分“类别层面合理”和“当前数据上适配”。一句描述可以对整个类别成立，却对当前域多数样本不适用；在整体数据集中有用的属性，也可能不适合某一张图片。若少数黑狗仍存在，黑色描述对它们可能有帮助，因此不能仅因某属性不占多数就断言它完全无用。

论文表述优先使用“目标域不匹配语义”“样本不适配语义”或“无关语义干扰”。句子重复和语义相近属于另一个维度，后续可单独研究，不能混用两种定义。

## 核心假设与结论判据

**主要待验证假设：从同一候选描述池中，根据目标域无标签视觉证据选择少量适配描述，比无差别融合全部描述获得更高分类准确率。**

为了把“数量变少”和“选得适配”分开，应同时检验两个比较：适配选择 K 条优于全量描述，且适配选择 K 条优于随机 K 条。只有超过随机选择，才能支持选择机制本身的价值；只有超过全量融合，才能支持少量适配证据更优的主要假设。不能只展示超过原始类名模板。

“不适配语义可能干扰预测”是机制假设，不是已经确定的事实。具体结果取决于不匹配程度、融合权重、其他描述的补偿作用，以及筛选是否丢失互补信息。新模型、更多细节、较低文本相似度，也都不自动等于更高分类准确率。

## 已有实验事实

以下为同一 DTD test 划分、CLIP ViT-B/16、1692 张图片、测试流种子 1 的探索结果。各组共用同一视觉特征和顺序，视觉缓存从空开始独立更新。

| 条件 | Top-1 准确率 | 当前能说明什么 |
| --- | ---: | --- |
| 原始 TDA 类名模板 | 44.80% | 已跑通且可重现的本机基线 |
| TDA + 官方旧 CuPL 全部 60 条/类 | 54.08% | 这套静态描述明显有效 |
| 官方旧池去除规范化文本完全重复项 | 54.26% | 本次只多正确 3 张，不能等同于目标域适配证据 |
| 官方旧池每类随机 10 条，固定种子 0/1/2 | 53.37% / 51.65% / 51.89%，均值 52.30% | 描述子集的构成会影响结果；这是三组描述抽样，不是三次测试流重复 |
| TDA + 本次新生成描述 10 条/类 | 50.53% | 高于模板，但低于旧池各个等数量子集 |
| 新描述全部均匀复制一次 | 50.53% | 均匀复制不改变均值文本原型，实际原型差为 0 |
| 新池首条描述额外复制 10 次 | 44.62% | 人为改变某条描述的相对权重可以损害本次表现 |
| 新池上的简单历史视觉原型动态 Top-3 | 50.12% | 低于新版静态 0.41 个百分点，尚无动态优势 |

官方旧池共 2820 条，按类别内规范化文本去重后合计 2745 条；新池 470 条全部唯一。旧、新池按类平均的文本嵌入两两余弦相似度分别约为 0.8895、0.8529。新池重复较少但准确率较低，说明重复程度不是效果的唯一决定因素。

这些结果**尚未直接验证主要假设**。此前动态 Top-3 只在新版 10 条候选池上运行，没有完成官方旧池上“全部 60 条、随机 K 条、适配 K 条”的配对比较；均匀复制、偏向性复制和完全去重实验也没有直接操作“与目标域不匹配的属性”。不得把这些结果写成已经证明目标域语义筛选有效。

新描述由用户要求的低成本 `gpt-6-luna` 子智能体生成。它与旧池的生成模型、提示设计和文本内容均不同；即使控制描述数量，也不能单独归因于模型年代或模型能力。生成记录和评估前文本清理过程均保留，不能将它直接称为“高质量新版描述”。

## 下一步最小对照实验

先固定官方旧 CuPL DTD 描述池，每类原始 60 条，不重新生成或按测试结果人工挑句。沿用现有数据划分、CLIP 权重、TDA 正负缓存参数和文本聚合方式。

| 实验组 | 描述处理 | 目的与状态 |
| --- | --- | --- |
| 模板 TDA | 原始类别模板 | 基线，已有 44.80% |
| 全量 CuPL | 每类全部 60 条平均融合 | 主比较对象，已有 54.08% |
| 随机 K 条 | 每类固定抽取 K 条，不根据图像选择 | 数量控制；K=10 的三组抽样已有记录 |
| 静态适配 K 条 | 仅根据验证阶段可用证据固定选择，测试时不更新 | 可选的第二阶段对照，用于区分固定适配与在线更新；尚未运行 |
| 在线适配 K 条 | 根据此前已到达的可靠无标签测试样本更新选择 | 下一步核心实验；官方旧池版本尚未运行 |

第一步只实现相关性驱动的最小端到端选择，检验它是否产生适配收益。混淆类别判别、语义互补性和其他 RDSS 组件随后独立增加、分别消融，不同时修改多个因素。K、可靠性阈值等设置在验证集确定并冻结，不以最终 test 准确率反复挑选。

## 在线适配方法的最小定义

为每类保留固定的候选文本向量。测试图像到达时，先用已有状态完成预测；对通过可靠性门控的样本，使用伪标签更新对应类别的历史视觉统计。将归一化的历史视觉特征聚合作为类别视觉原型，根据候选描述与该原型的相似度选择 Top-K 描述，再聚合为新的类别文本原型，供后续样本使用。

概念上，类 c 在时刻 t 使用的选择依据是此前可靠样本形成的视觉原型 v̄(c, t−1)，候选描述向量为 u(d)：

```text
相关性(d, c, t) = cosine(u(d), v̄(c, t−1))
选中集合(c, t) = 对同一类候选池按相关性选取 Top-K
文本原型(c, t) = normalize(mean(选中描述的单位化文本向量))
```

没有历史证据的类别使用预先固定的全量描述原型作为共同初始状态。当前样本完成预测后才更新文本记忆，避免把当前图像自身参与选句的收益和历史测试流适应混在一起。真实标签仅用于评价，不进入选句、原型更新或可靠性门控；不得利用未来测试图片预先计算全测试集类别均值。

该最小方法仍可能选择到普遍适用却缺少类间判别性的描述，也可能受错误伪标签影响。若它不优于全量组，应先记录失败发生的类别和更新覆盖情况，再在验证集上研究可靠性和判别性，而非修改测试标签或直接认定核心假设成立。

## 公平性与需要记录的证据

各组固定同一描述池、CLIP 主干、数据划分、图像预处理、测试顺序、视觉缓存参数和归一化方式。静态文本按 CuPL 方式逐条编码、单位化、求平均并再次单位化，不将多条描述拼成一段长文本。改变文本后，各组的伪标签与视觉缓存会自然变化，应从空缓存独立运行并明确记录这一点。

随机 K 条组使用预先固定的多个抽样种子；在线组应在多个测试流顺序下复验，报告均值及波动，不仅展示最好的一次。当前已有旧池三个 K=10 抽样结果只提供有限的描述抽样参考。

除总体 Top-1 外，保留逐图预测、按类准确率、每类被选择的描述及其变化、可靠样本数量、更新覆盖率，以及运行耗时。若要支撑“目标域不匹配语义被过滤”的机制，还应展示固定案例中被保留和被排除的具体属性及对应视觉证据；不能仅凭文本余弦相似度较低就断言语义适配更好。

后续可单独设计属性分布变化的受控诊断：使用预先定义、可核查的属性或域标记划分场景，观察描述选择是否随实际分布变化。狗的颜色例子目前只是解释性例子，尚未构建对应数据或完成这种实验；不得将人为重复一句话的压力测试当作该属性偏移实验。

## 当前结论与后续判断

当前已知：静态 CuPL 在本机 DTD 上有效；不同描述池与不同子集会带来明显准确率差异；均匀重复、偏向性重复和目标域不匹配是不同问题。

当前未知：基于目标域证据筛选官方旧池中的少量描述，能否稳定超过全量融合和随机等数量子集；简单相关性选择是否足够，以及后续判别性、可靠性机制分别贡献多少。

如果在线选择同时超过全量与随机组，并在多测试流中稳定复现，可表述为“结果支持在该评测设定下选择目标域适配语义的有效性”。若只超过随机组而低于全量，只能说明选择优于随机，不能声称少量适配描述优于全部融合。若未超过，应保留结果并进一步分析，不预设最终结论。
