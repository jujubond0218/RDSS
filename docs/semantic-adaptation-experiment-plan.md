# RDSS 研究目标与后续消融计划

更新：2026-10-21。本文件是当前唯一研究计划入口，取代早期DTD阶段的“下一步”安排；早期事实已整理至 [DTD探索记录](experiments/dtd-cupl-exploration.md)。本文件所列优化与实验尚未执行，当前可运行实现仍为 [第二版](experiments/rdss-v2.md)。相关文献、发表状态和借鉴边界只在 [文献对照](RELATED_WORK.md) 维护。

## 论文目标与范围

用户明确学校不要求必须提高准确率，但必须体现方法创新、完整逻辑与工作量。目标是在免训练CLIP测试时适应下，研究可信视觉证据驱动的RDSS选择与动态语义缓存，而非追求SOTA或逐个测试集找涨点。实现规模、受控消融、适用条件与失败原因共同构成研究工作，不用堆砌模块替代贡献。

研究问题：离线生成的描述库覆盖广，不同描述在当前视觉分布中的作用不同；如何利用在线可信证据选择相关、具有混淆类别判别力且互补的语义，并在测试分布变化时稳定更新？这是待验证的问题，不预设全量平均易受噪声破坏，也不预设少选描述更快或更准。

固定流程为“宽覆盖候选库→历史可信视觉证据→RDSS选句→语义缓存更新→与模板/TDA视觉分支融合”。双缓存指视觉与文本语义缓存，TDA正负缓存是视觉分支内部结构。编码器冻结、无梯度回传、无测试标签和域边界输入，默认先预测后更新；当前图像查询若未来加入，必须单独标明协议并做对照。

## 两个拟论证的贡献

第一，提出面向在线伪标签证据的RDSS联合语义选择定义，明确相关性R、混淆判别性D与冗余抑制S的职责及协同关系。重点在证据可靠性约束下如何估计与选择，不声称首次生成描述、首次判别性选句或首次使用MMR。

第二，构建可靠性与时效共同作用的动态语义缓存更新，区分“预测是否值得信”“证据是否仍适用”“不同图片是否提供互补外观”。重点验证语义选择和视觉状态协同的行为及边界，不把已有时间衰减或均值混合作为单独原创。

上述是拟贡献表述，不是已获独立实验支持的结论。方法未提高准确率时仍可报告污染减少、响应改变、覆盖损失等真实发现；这些发现不能改写成不存在的性能优势，也不构成毕业结果保证。

## 方法整理：先核心，再证据，再动态

核心评分优先恢复显式R/D/S，作为职责清楚、便于消融的最小方法。候选形式为：

```text
Score(d | selected) = R(d) - lambda_D * P_conf(d)
                     - lambda_S * max_cosine(d, selected)
```

R表示对可信本类视觉证据的支持；P_conf表示对局部混淆类别的误激活风险，可以只惩罚超过稳定类别参照的响应，避免将Rel再次完整加回形成2Rel。冗余项仅衡量已选描述间相近程度，不把“目标域不适配”混叫冗余。具体数学定义和尺度在开发阶段固定；不因公式看起来像MMR就声称目标具有次模性或贪心最优保证。

第二版默认用间隔损失替代显式R；损失在较大正间隔下迅速变小，而冗余权重保持0.1，可能发生尺度失衡。先记录三项分布、单步选择贡献和聚合方式，再对照显式R、当前间隔目标、逐句/归一化集合评分，避免将结构变化和Disc开关混为同一消融。该解释尚未被因果实验确认。

证据层优先借鉴ARTTA的冻结可靠性锚点与RADC的间隔/不确定性联合评估。先使用冻结模板间隔与原门控，再单独加入少量多视图不确定性；不同视图需重新编码，不能从现有单视图均值虚构方差。视图定义、数量、归一化方式与权重映射先在开发协议冻结。仅凭低熵或高一致性均不能保证正确，自信的共同错误依然可能污染记忆。

必须区分同一图片增强后的波动与同类别不同图片之间的差异。后者可能是合法颜色、姿态、品种或域变化，不能直接把类内集中程度低解释为噪声；当前concentration仅是第二版启发式，不是可靠性真值。

动态层先保留简单的证据时效与有稳定先验的更新，逐项比较，不同时引入额外编码器、图网络和新选择器。归一化混合 `p=normalize(M*p_selected+kappa*p_all)` 可由带稳定先验的二次目标解释，但这是建模依据而非性能保证。M应体现有效支持，如何结合质量、时效和互补性是待验证设计，不直接累计接收次数。

“候选先试用、后续样本检验”“短/长期证据分别读取”“BDC依赖统计”“额外检索空间”仅列为后续候选。启用任何一个前需说明现有消融仍无法回答的问题和额外成本；不要求全部实现。

## 分组消融矩阵

| 实验组 | 优先比较条件 | 要回答的问题与记录 |
| --- | --- | --- |
| RDSS组成与评分 | R、R+D、R+S、R+D+S；固定全量和同数量随机子集；逐句/集合方式单独比较 | D/S各自贡献与互补；三项尺度；选句及语义分支表现 |
| 证据可靠性 | 熵门控；熵+模板/TDA一致；冻结锚点间隔；再加多视图不确定性 | 错误接收比例与正确样本覆盖同时变化；不能仅靠拒绝更多样本获得纯度 |
| 证据时效 | 无衰减；同类到达次数衰减；全局时间衰减 | 普通随机流和连续域流的响应/覆盖权衡；阶段初末成绩及证据权重 |
| 更新幅度 | 直接替换；固定比例混合；支持量混合；可靠性加权混合 | 稳定性是否压掉有效适应；纠正/新增错误、原型偏转与域回归 |
| 敏感性与鲁棒性 | 预设k与队列规模、原始/属性错配池、随机/连续域/域回归流、多顺序种子 | 参数稳定范围、候选池与顺序影响；不挑最优种子或刻意制造优势 |

先做核心四条件，再按研究需要补D、S或全因子对照；不是所有因素全笛卡尔积。方法条件固定后，核心比较使用至少3个预设流顺序；随机描述抽样种子与流顺序种子分开记录。参数敏感性只用少量预设值，开发结束后冻结，不在保留评价上选最优值。

共同对照包括模板TDA、固定全量、同数量随机描述和完整RDSS；必要时加入固定一次选择以隔离在线更新。固定同一候选池、权重、预处理、视觉缓存参数及流顺序。语义消融优先共享模板驱动视觉状态；改变视觉门控的实验单列，不能混入仅改语义条件。

## 数据访问、评价与可核查工作量

现有Flowers/PACS/NICO测试流已被多次用于设计，继续重放一律标注探索性，不是独立验证。先核查可用图片和既有Zhou划分，在不改原划分/类别编号的前提下建立开发与保留评价清单，保证内容哈希不重叠；对于已观察过的官方test，新的顺序不能恢复盲测身份。若使用现有train/val开发，明确用途和访问记录；人工Flowers筛选曾接触验证图，不能默认这些图从未被观察。

每种流预先固定排流规则、域持续长度、回归是否换图和缓存是否持续；类别/域标签可用于构造评估场景及事后统计，不进入RDSS。若开发集标签用于选择阈值或超参数，必须如实说明，不声称完全没有目标域监督。

主要指标为Top-1、类别平均、逐样本配对纠正/损坏、跨顺序均值与波动。机制指标为接收纯度/覆盖、更新覆盖类别、选择变化、域切换响应、原型偏转、阶段回归表现。真实标签只用于评分/诊断，伪标签一致不等于独立模型验证。小样本几张差异不直接表述为显著收益。

资源指标包括离线生成/编码成本、在线选择与读取耗时和内存。使用缓存特征重放的时间不包含编码；多视图或额外编码器单列预算，少选8句不自动使已预计算的全量原型推理更慢。图示和案例事先说明抽样规则，不能只展示有利类别。

每次保存参数与协议、输入/源码哈希、流与描述种子、逐样本预测、选句事件、证据权重及全部消融结果。结果目录与私有原始数据保持忽略，只提交获授权的源码/文档。不同池、融合方式或视觉更新协议的历史结果不能混放同一主表作直接归因。

## 执行顺序与完成判据

| 阶段 | 交付 | 开始下一阶段的条件 |
| --- | --- | --- |
| P0 开发协议 | 图片与内容哈希清单、历史接触说明、种子/比较矩阵 | 明确开发、探索和保留评价边界 |
| P1 RDSS核心 | 评分定义、尺度检查、R/D/S和聚合方式消融 | 目标组成清楚，完整保留成功与失败结果 |
| P2 可信证据 | 锚点间隔与视图不确定性对照 | 纯度与覆盖同时报告；成本可核查 |
| P3 动态缓存 | 时效与幅度消融、切换/回归分析 | 区分响应变快与分类变准，不偷用域边界 |
| P4 冻结评价与写作 | 多顺序总表、机制图、资源表、方法与局限章节 | 规则冻结后统一评价，不据评价结果继续改选配置 |

论文可按“问题与已有方法→RDSS联合选择→可靠动态缓存→受控实验与局限”组织。可成立的结论必须对应实验：超过模板不等于超过全量，超过随机不等于少量胜过全量，减少噪声入选不等于准确率提升。无需所有数据集涨点，但创新陈述、工作量、可复现证据与结论必须一致。
