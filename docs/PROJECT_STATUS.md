## 待解决与下一步

先审查显式R/D/S及评分尺度：第二版默认把显式相关性系数置零，相关性隐含在间隔损失中；间隔损失饱和后冗余可能主导，是待检验的机制解释。恢复职责清楚的RDSS目标后，再研究冻结锚点可靠性与多视图不确定性；同一图片的视图波动不能与同类图片的正常多样性混为一谈。

证据时效已改善响应，但未保证分类收益；渐进先验减少偏转也可能压掉有效变化。下一轮按“开发协议→核心评分→R/D/S消融→可靠证据→动态更新→冻结评价”推进。当前图像临时查询、候选试用、BDC统计和额外检索编码器均未实现，也不是必选模块。具体目标、实验矩阵与完成判据统一见 [研究计划](semantic-adaptation-experiment-plan.md)。
