## 修改与时序

`rdss.py` 用归一化选句集合原型的分类间隔代替逐句 `2Rel-Neg`。贪心加入每条候选时，重新归一化当前选句向量和，再评价其对可信正类证据和混淆负类证据的效果。正类间隔是新原型分数减去混淆类别全量原型的最高分；负类间隔是该负类全量原型分数减去新原型分数。全量参照在选择期间固定，防止竞争类相互漂移。混淆类取历史模板事件的其他 top3；没有候选列表时，正类参照定义为全部其他类。负类必须已有可信证据。

令 `ell(m)=softplus(-100*m)/100`，采用类别平衡损失 `L=(E_pos ell(m_pos)+sum_d freshness_d E_d ell(m_neg))/(1+sum_d freshness_d)`。每类内部按证据权重平均；重复同一负类样本不会人为扩大该类权重。完整选择分数为 `-L-0.1*Red`，Red 为与已选描述的最大非负余弦相似度。关闭判别项的对照使用集合原型的正类平均相关性。这里的尺度是新的研究选择；沿用冗余权重 0.1 不等于已证明它在新目标下最优。

全局时间证据使用 `q_i*2^(-(t-t_i)/(4*C))`，其中 C 为类别数，q=1-模板归一化熵。它取代完整版本原有的同类到达次数衰减；不输入域边界或标签。类队列仍最多32条。负类整体时效为最近一次接收时间对应的半衰减权重，不在负类归一化后将其抵消。只改评分的消融保留原0.9同类接收次数衰减。

全量原型始终作为稳定先验，实际读取为 `normalize((1-alpha)*p_all+alpha*p_selected)`；`alpha=concentration*mass/(mass+4)`。mass 为带可靠度和时间衰减的证据总质量，concentration 为这些单位视觉向量的加权均值长度。首条完全可信证据的 alpha 至多0.2；久未出现的类别影响逐渐减弱。读取时批量计算各类系数，当前图像不会写入记忆，也不会提前参与选句。

模板/TDA 一致与归一化熵≤0.2的接收门控保持不变；先输出当前预测，再更新语义状态。原始 `tda_runner.py`、`visual_cache.py` 与 `semantic_cache.py` 未改变。当前图像驱动的临时描述查询尚未实现，本版不声称解决新域第一张图的语义延迟。

## 固定实验协议

入口 `experiments/evaluate_rdss.py` 重放三个历史完整流，默认依次 Flowers-102 2463张、PACS 700张、NICO++ 1120张；`--limit 28` 仅做短流检查。四个新条件依次为：集合相关性、只改间隔评分、评分加时间衰减、评分加时间衰减与渐进先验。k=8、队列32、混淆top3、冗余0.1、语义融合权重1不做测试集搜索；完整版本的时间半衰期为4*C，先验强度4。这些数值是本轮预设，不是验证集选出的最优参数。

TDA 与首轮 RDSS 对照读取历史保存的 logits，全量语义分支则重新计算，并逐张断言与历史全量 logits 完全相同。所有新条件重放相同的模板接收事件，按相同顺序独立从空记忆开始。真实标签和域阶段仅在所有在线预测完成后用于计分。该实验隔离语义选择变化，不重新编码图片和文本，也不重新执行原始 TDA。

这些测试流已经用于方法诊断，本轮属于探索性复测，不能作为新的独立验证或用来反复寻找参数。参数和协议在正式计分前写入运行目录。保存输入/源码哈希、工作区状态、逐样本预测与 logits、全部选句事件、更新系数、最终选句和阶段成绩。历史诊断 `experiments/diagnostics/diagnose_rdss.py` 明确读取首轮结果中的旧源码快照，仍用于复现首轮组件。

完整第二版相对首轮分别多6、3、6张；相对全量Flowers纠正13张、新错18张，PACS没有改变任何类别预测，NICO没有纠正、增加2张错误。不能将此结果称为已稳定超过全量。类别平均准确率分别为72.0509%、97.5714%、93.0357%。既有诊断中首轮逐句相关性＋冗余Flowers1822、NICO1047，仍优于本轮对应新版；新的集合相关性不是原来的逐句Top-k，两者不可混称。

仅改间隔在新集合相关性控制之上分别多20、少1、多2张，但该对照不等同于“只在旧方法上替换Disc”：它同时使用新的归一化集合贪心。因此只能归因于新框架内部启用间隔目标的变化。进一步分离聚合方式和判别性目标仍需要验证协议下的消融，不能从本轮测试表直接断言所有设计均有效。

时间加权使NICO阶段末35张的当前阶段证据占比从43.78%～54.99%升为65.19%～72.06%；阶段初35张从4.61%～8.76%升为7.86%～13.28%。此统计根据相同接收历史、事后真实类别与阶段重建，只证明权重响应变快，不等于准确率必然提升。NICO间隔＋时间相对仅间隔多1张，Flowers反而少6张，提示无序流中的覆盖与域流中的响应需要不同证据作用机制，而非单纯继续加快衰减。

渐进先验将最终原型相对全量的平均夹角从间隔＋时间的14.029°/13.825°/12.886°降为5.520°/7.107°/6.025°。Flowers恢复9张，NICO损失4张；更小的偏转不自动等于更好的预测。完整第二版的语义分支单独正确数为1783/683/1041，全量为1802/683/1042，Flowers语义选择仍需优先修复。

`experiments/diagnostics/audit_rdss_v2.py` 独立核对CSV、logits正确数、输入与快照哈希、四条件接收事件对齐、选句唯一性及更新系数范围；全部通过，结果在 `audit.json`。本轮保持预设参数，不因观察到上述测试结果选择最佳条件作默认，也不继续在同一测试流搜索参数。后续执行顺序与贡献目标统一见 [研究计划](../semantic-adaptation-experiment-plan.md)，不在本报告维护第二套计划。

历史诊断入口切换到显式旧源码快照后，已完整重放三数据集，旧版全部融合logits、选句与组件正确数精确复现，验证目录 `project_R/runs/rdss_diagnosis_20261021_003512`，日志为 `project_R/logs/rdss_v2_historical_replay_20261021.log`。这样当前算法更新与历史实验复现各有明确入口。

## 后续审查备注（2026-10-21，非新增实验）

默认discrimination_weight=1时，显式相关性项系数为零，相关性隐含在间隔损失中；较大正间隔下损失快速减小，冗余项可能主导选句。这是从目标形式提出的尺度假设，尚未经过额外因果消融确认。当前concentration衡量同类图片聚合的一致程度，不是同一图片多视图不确定性，不能把两者互换。拟恢复显式R/D/S并区分可靠性与覆盖的方案尚未实现，文献依据见 [文献对照](../RELATED_WORK.md)。
